# Semantic HTML Examples

A demo page showcasing semantic HTML5 elements, with a short explanation of what each one is for.

![Demo](screenshots/demo.png)

## What it is

A single-page reference that demonstrates semantic HTML tags in action — the elements that give a page meaning, not just layout. Each section shows the tag and explains when to use it.

## Elements covered

- `<article>` — a self-contained piece of content that makes sense on its own and can be distributed independently.
- `<section>` — a thematic grouping of content.
- `<header>` and `<footer>` — introductory and closing content for a page or section.
- `<figure>` — self-contained content such as illustrations, diagrams, or photos, optionally with a caption.

## Tech Stack

- Plain HTML (no CSS framework, no JavaScript)

## How to Run

Just open the file in a browser — no install, no server needed:

```bash
# Option 1: open directly
open index.html

# Option 2: serve it locally
python3 -m http.server 8000
# then visit http://localhost:8000
```
